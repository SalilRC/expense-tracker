# Quickstart: Expense Tracker

## Prerequisites

- A modern web browser
- Optional: a simple static server such as Live Server, Python http.server, or VS Code Live Server

## Run the App

1. Open the repository root in a browser.
2. Load the app by opening [index.html](../../index.html) directly or by serving the folder with a static server.
3. Use the form to add an expense with a date, description, category, and amount.
4. Confirm that the report updates immediately and that the data remains after a page refresh.

## Validation Scenarios

- Add a valid expense and verify that the correct category total and grand total appear.
- Submit an invalid expense and verify that validation feedback appears and the expense is not added.
- Refresh the page and verify that previously saved expenses remain visible.
